### Live side projects

These repos hold the published sites. The code that builds them is private.

- **[Inshore Briefing](https://blakezurman.github.io/inshore-briefing-site/)** ([repo](https://github.com/BlakeZurman/inshore-briefing-site)):
  a home-screen web app that tells me when to go fishing around Clearwater. It pulls NOAA tide and current
  predictions and National Weather Service forecasts, rates each window, and refreshes through the day on
  GitHub Actions.
- **[Fantasy football reports](https://blakezurman.github.io/espn-fantasy-site/)** ([repo](https://github.com/BlakeZurman/espn-fantasy-site)):
  lineup, waiver, and drop recommendations for my ESPN league, from a Python pipeline that pulls league and
  NFL usage data, checks it, and publishes a small web app.
